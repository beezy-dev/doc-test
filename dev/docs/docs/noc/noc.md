# netapp-openshift-console-[trident,protect]

The open-source projects netapp-openshift-console-[trident,protect] have been designed to improve the user experience connecting Red Hat OpenShift with the NetApp portfolio.

netapp-openshift-console-[trident,protect] deploys as a native Red Hat OpenShift console plugin enabling a graphical user interface to:  

- Accelerate the deployment of Trident and Trident Protect.
- Simplify the usage of Trident features like volumes, snapshots, etcs.
- Simplify the usage of Protect features like Application Reference, Scheduling, Snapshots, Backups, Restore, etcs.
- Provide application pattern deployment for fast prototyping up to production. 
- Enable dataset management for workload running in Red Hat OpenShift, OpenShift AI, and Developer Hub.

## Pre-requisites and Deployment

These projects are currently in a pre-release phase and requires an Early Access Program agreement granting access to deploy the plugins on your Red Hat OpenShift cluster.   
The netapp-openshift-console-[trident,protect] plugins are compatible with Red Hat OpenShift Container Platform **4.14, 4.15, 4.16, and 4.17**.
